最終更新: Unity 6000.4.3f1 3D・ビルトインパイプライン

1. 全体像何のゲームで、誰がどう遊ぶのか

カメレオンナイトは、暗い夜のジャングルを舞台にした、2人で遊ぶ協力ゲームです。専門店などでの展示・体験を想定しています。

2つの役割

役割操作する人やること
メイン(カメレオン)キーボード(展示ではセンサーなどに置き換え予定)逃げ回る。攻撃手段はない。
灯り役(協力プレイヤー)スマホ(傾き/タッチ)。無い時はマウス懐中電灯を動かし、敵に光を当て続けて倒す。

面白さの核: 「1人では戦えない」ので、2人の息が合わないと勝てません。灯り役は1体に狙いを定め続ける必要があり(逸らすと敵が回復する)、メイン役は敵を灯りの範囲に誘導するように逃げます。観ている人にも役割が分かりやすく、展示向きです。

3つの作業場所

場所中身役割
mockup/ブラウザで動くHTML試作3種アイデアと遊びの検証。作り直しが速い。
Assets/Unityのゲーム本体展示で実際に使うもの。
docs/このページ状況の整理と説明用。

2. HTMLモックアップ3種なぜ先にHTMLで作ったのか、それぞれ何を試したのか

Unityは起動・ビルドに時間がかかるため、遊びのアイデアはまずブラウザ(three.js)で素早く試作しました。ファイルを開くだけで動くので、他の人にも見せやすい利点があります。

ファイルコンセプト試したこと
chameleon-3d.html擬態するステルス止まると周囲の色に溶け込み、動くと目立つ。見つかり具合を表す「発見ゲージ」、ライフ3、ミニマップ、効果音。
maze3d.html迷路×非対称対戦圧力マット役(メイン)とスマホ傾き役(サーチライトで妨害)の対戦。一本道だと詰むため、迷路に抜け道(ループ)を追加。当たり判定を軸ごとにスライドさせる方式に修正。
chameleon-survivor.html協力サバイバーメインは逃げるだけ、灯り役が敵を焼き払う。時間で敵が増える。Unity版の元になった試作。
補足: maze3d.html と chameleon-survivor.html は現時点でGitにはコミットしていません。GitHubに上がっているのは chameleon-3d.html のみです。

3. サバイバーのルールと数値「どういう仕組みで倒すの?」に答えるための詳細

倒し方(ダウンゲージ)

  1. 敵は光の円(半径2.4)の中にいて、かつプレイヤーから1.6より離れている間だけ、体力(ダウンゲージ)が減ります。
  2. 光を外すと、ゲージは自然回復します。だから1体に当て続ける必要があります。
  3. ゲージが0になると、敵は縮みながら浮いて消え、撃破数が1増えます。

なぜ「プレイヤーの近くには光が効かない」のか: これが無いと、灯りをプレイヤーの真上に置きっぱなしにするだけで、寄ってきた敵が全部焼けてしまいます。その必勝法を構造的に無効にするための調整です(HTML試作のコメントにも同じ意図が書かれています)。

敵の種類

種類速さ接触ダメージ/秒ダウン体力光での減少/秒回復/秒特徴
蛾(moth)2.610344416小さく速い。すぐ倒せるが数が多い。
大型(brute)1.5221103820遅いが硬く、痛い。
突進(dasher)2.016454418ギミック: 0.6秒その場で黄色く光り(予告)、一直線に突進(0.45秒・速さ9)。約8秒後から出現。
光避け(skulker)2.912365022ギミック: 光が近づくと逃げる。壁際や角に追い詰めて当てる必要がある。約20秒後から出現。
分裂(splitter)1.914804018ギミック: 倒すと小さな蛾が2体飛び出す。約14秒後から出現。

時間で難しくなる仕組み

  • 出現間隔 = max(0.3, 1.5 − 経過秒 × 0.06) 秒。開始直後は1.5秒ごと、約20秒で下限0.3秒になります(HTML試作より大幅に速い設定)。
  • 大型が出る確率 = min(0.3, 0.04 + 経過秒 × 0.012)。最初は4%、約22秒で30%(上限)。突進・分裂・光避けは、それぞれ一定時間が経ってから、少しずつ混ざり始めます。
  • 敵はプレイヤーの周囲15〜18の距離にランダムに出現します。画面内の敵は最大45体で、増えすぎて画面が騒がしくならないようにしています。

プレイヤー側

  • HP 100。敵に触れる(距離0.9未満)と、重なっている敵の中で最大の接触ダメージだけを毎秒受けます(合算ではありません)。さらにダメージ倍率2.2をかけていて、HTML試作より短時間で倒されます。
  • 移動速度 5.6。移動できる範囲は中心から±19。
  • HPが0でゲームオーバー。制限時間はなしで、生き残った時間を競います。ダメージ倍率と敵の増え方を上げることで、早めに決着がつく設計にしています(展示の回転を上げるため)。
  • ベストの生存時間と撃破数は端末に保存されます。

4. 技術のしくみスマホ連携・シーン生成・当たり判定・カメラ・UI

スマホ連携(どうやって繋がるのか)

  1. Unityゲームが起動すると、PC上に小さなWebサーバー(HTTP:8787 / HTTPS:8788)が立ちます。PointerServer.cs が担当します。
  2. 画面右上に、そのURLのQRコードが出ます。同じWi-Fiのスマホで読み取ると、専用ページが開きます。
  3. スマホは指の位置(タッチ)または端末の傾きを、画面上の位置(0〜1の座標)に直して、約20回/秒でPCに送ります。
  4. Unity側は、その座標から画面にレイを飛ばし、地面に当たった位置を懐中電灯の狙いにします(FlashlightController.cs)。
  5. スマホが繋がっていなければ、マウスの位置を使います。HUDに「スマホ操作中/マウス操作中」と出ます。
HTTPSがある理由: iPhoneの傾きセンサーは安全な接続(HTTPS)でないと許可されないことがあるためです。自己署名証明書をWindowsのPowerShellで作っています。QRの読み取りと実機接続はまだ確認できていません。

シーンの作り方(なぜボタンを押す必要があるのか)

このプロジェクトは、地面・木・岩・プレイヤーなどを手で配置していません。メニュー ChameleonNight › Build Survivor Scene が、SurvivorSceneBuilder.cs の命令どおりに一括生成し、ChameleonSurvivor.unity として保存します。コードを変えたら、もう一度ボタンを押さないと反映されないのはそのためです。

見た目の部品(球・コーン・パネル・ロゴ・QR)も、画像ファイルを使わずコードで生成しています。既存プロトタイプから続く方針で、素材の管理が要らない代わりに、見た目は簡素です。

当たり判定(なぜ木を通り抜けなくなったのか)

Unityの物理エンジンは使わず、木・岩などを円として登録し(SurvivorObstacle.cs)、プレイヤーと敵が動いた後に「円にめり込んでいたら外へ押し出す」方式です。軽く、動きも滑らかです。最初は木の幹だけを当たり判定にしていたため、樹冠の下を通れて「貫通」に見えました。今は樹冠まで含めて拡大しています。

カメラと左右の向き

  • カメラは斜め上(0,8,8)から、常にプレイヤーを画面中心にして追従します(SurvivorCameraFollow.cs)。
  • A/Dが逆になった理由: HTML試作(three.js)は右手座標系、Unityは左手座標系のためです。同じ符号だと左右が反転するので、Unity側でX方向の符号を反転させました。

UIと明るさ設定

  • 画面表示はUnity標準の即時描画(OnGUI)で作り、角丸パネルやロゴはUITextureFactory.csが生成します。
  • 配色は「夜の緑×灯りの金」を基本色として統一しています。
  • Escのポーズ画面に、画面の明るさスライダー(×0.2〜×5)があります。環境光と月明かりの強さに倍率をかけるだけの、開発者向け設定です。設定値は保存されます。

素材

  • 木・岩・草などは Kenney Nature Kit(CC0=著作権フリー、商用可、表記不要)。Assets/Models/KenneyNature/にFBX 329点とライセンス文を置いています。
  • 主人公・敵は現在球とコーンの簡易モデル。主人公はTripo AIで作る予定です。

5. Unityの操作手順どのメニュー・ボタンを押すのか
下の2つの図は説明用の簡易イラストです(Unityの実際のスクリーンショットではありません)。
  1. Unityでプロジェクトを開く
    Unity Hubで chameleon-night-prototype を開きます。エディタは1つだけにしてください。
  2. メニューからシーンを作る
    上部メニューの ChameleonNight → Build Survivor Scene を押します。
  3. シーンを開く
    下の Project パネルで Assets › Scenes › ChameleonSurvivor をダブルクリックします。
  4. Playする
    画面上部中央の▶ボタンを押します。タイトル画面で Enter / Space / クリック、または「はじめる」で開始です。
  5. Gameビューで確認する
    Game タブに映ります。電球や太陽のマークが出る場合は、Gameタブ右上の Gizmos ボタンをOFFにします。
